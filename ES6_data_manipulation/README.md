# ES6 Data Manipulation

This project covers ES6 data manipulation concepts including:
* Arrays (map, filter, reduce)
* Typed Arrays
* Sets
* Maps
* WeakLinks

## Files
* `0-get_list_students.js`: Basic list of objects.
* `1-get_list_student_ids.js`: Map function usage.
* `2-get_students_by_loc.js`: Filter function usage.
* `3-get_ids_sum.js`: Reduce function usage.
* `4-update_grade_by_city.js`: Combining filter and map.
* `5-typed_arrays.js`: ArrayBuffer and DataView.
* `6-set.js`: Set data structure.
* `7-has_array_values.js`: Checking values in Set.
* `8-clean_set.js`: String manipulation within Sets.
* `9-groceries_list.js`: Map data structure.
